# Telecom Customer Churn Prediction

This project involves a machine learning approach to predict customer churn in the telecom sector.

## 🔍 Problem Statement
Churn prediction helps telecom companies identify customers who are likely to stop using their services, allowing them to take proactive retention measures.

## 📊 Dataset
The dataset includes customer demographics, account details, services used, and whether or not the customer churned.

## 🧠 Techniques Used
- Exploratory Data Analysis (EDA)
- Data Cleaning and Preprocessing
- Feature Engineering
- Model Building using Logistic Regression, Decision Trees, and Random Forest
- Evaluation using Accuracy, Precision, Recall, and Confusion Matrix

## 📈 Results
Achieved good predictive performance using ensemble methods and visualized important features influencing churn.
